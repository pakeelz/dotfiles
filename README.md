# My Personal Dotfiles
These dotfiles contain several applications with default settings that I’ve modified slightly, such as:

1. Hyprland
2. Nvim
3. Noctalia
4. Zed
5. Pictures
6. Kitty

If you install Hyprland using the Cachyos installer and you like my dotfiles, the script below will most likely work:

```bash
curl -fsSL https://raw.githubusercontent.com/pakeelz/dotfiles/main/install.sh | bash
```
